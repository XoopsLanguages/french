Installation de XOOPS

Première installation

Préface :

XOOPS est un logiciel open source Système de publication Web orienté objet écrit en PHP. C'est un outil idéal pour développer des sites Web communautaires dynamiques de petite à grande taille, des portails intra-entreprise, des portails d'entreprise, des blogs et bien plus encore.

XOOPS est publié selon les termes du Licence publique générale GNU (GPL) version 2 ou supérieure, et son utilisation et sa modification sont gratuites. La redistribution est gratuite tant que vous respectez les conditions de distribution de la GPL.

Exigences

  • Serveur WWW (Apache, NGINX, IIS, etc.)
  • PHP 8.2 ou supérieur, 8.4+ recommandé
  • MySQL 5.7 .8 ou supérieur, MySQL 8.4.5+ recommandé

Avant d'installer

  1. Configurez correctement le serveur WWW, PHP et le serveur de base de données.
  2. Préparez une base de données pour votre site XOOPS.
  3. Préparez le compte utilisateur et accordez à l'utilisateur l'accès à la base de données.
  4. Rendre les répertoires et les fichiers accessibles en écriture : %s
  5. Pour des raisons de sécurité, il est fortement conseillé de déplacer les deux répertoires ci-dessous hors de racine du document et modifiez les noms des dossiers : %s
  6. Créer (s'il n'est pas déjà présent) et rendre les répertoires accessibles en écriture : %s
  7. Activez les cookies et JavaScript de votre navigateur.

Installation locale

Si vous exécutez un environnement local à des fins de développement ou de test, assurez-vous que vous disposez de la version précédente exigences satisfaites. Une fois cela fait, copiez le contenu du htdocs répertoire (du XOOPS fichier de distribution) au chemin du document racine de votre environnement Web. Une fois les fichiers copiés là-bas, vous pouvez démarrer l'installation en pointant votre navigateur sur "http://votresite.com". Cela lancera le processus d'installation.

Installation sur une plateforme hébergée

Si vous exécutez dans un environnement hébergé, décompressez les fichiers XOOPS localement ou sur le serveur si vous avez accès au shell (c'est-à-dire SSH). Une fois terminé, assurez-vous de déplacer ou de copier tous les fichiers XOOPS du htdocs vers votre répertoire Web racine (votre fournisseur fournit généralement des instructions à cet emplacement). Une fois les fichiers copiés, vous pouvez démarrer l'installation en pointant votre navigateur vers " http://votresite.com". Cela lancera le processus d'installation.

Poursuite de l'installation

Suivez simplement les instructions étape par étape dans le programme d'installation.
