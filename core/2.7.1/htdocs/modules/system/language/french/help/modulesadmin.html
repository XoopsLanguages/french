Aide : Modules

Descriptif

Les modules sont des constructions logicielles qui, profitant de l'infrastructure fournie par XOOPS, permettent au webmaster de proposer aux utilisateurs du site un contenu dynamique ou statique généré à l'aide d'une interface Web qui est le plus souvent très simple à utiliser.

Une partie de la puissance de XOOPS réside dans la manière dont les modules sont gérés. Le webmaster peut facilement installer, désinstaller, activer ou désactiver n'importe quel module spécifique (sauf le module Système, pour des raisons évidentes). Il est également possible de renommer les modules, et de déterminer l'ordre dans lequel ils seront apparaissent à l'utilisateur final dans le menu du site (si vous souhaitez qu'ils apparaissent), car vous pouvez également fournir des fonctionnalités cachées, en définissant des modules actifs qui n'ont aucune présence visible pour l'utilisateur occasionnel. Par exemple, vous pouvez définir un module comme non visible dans le menu en désactivant l'option cochez l’icône dans la colonne Menu. Ainsi, pour le module Actualités, vous pouvez ensuite envoyer un message privé à un groupe sélectionné de vos utilisateurs et leur dire d'accéder à ce répertoire en tapant l'adresse dans le champ URL, quelque chose comme http://www.yoursite.com/modules/news.

Pour modifier l'ordre des modules (ce qui sera reflété dans le menu), il vous suffit de glisser-déposer les modules à l'emplacement souhaité.

L'installation des modules nécessite une certaine planification, à la fois pour les modules à afficher et également pour la disposition sur les pages. C'est une bonne idée de consulter d'autres sites XOOPS et de voir quels modules sont utilisés pour afficher différents types de contenu. Cela se fait facilement en ouvrant n'importe quel site XOOPS et en survolant les liens de menu sur les panneaux latéraux gauche et droit. Regardez en même temps les URL affichées dans la barre d’état de votre navigateur. Vous devriez voir des adresses comme celle-ci : http://the_site.com/modules/news/.... Tous les modules sont stockés dans le répertoire /modules/, donc le secteur suivant du L'adresse (dans cet exemple « news ») montre le module qui affichera le contenu de ce lien de menu.

Si vous ouvrez la page du lien, elle affichera un exemple de la façon dont le module est utilisé et le type de contenu qu'il affiche. L'examen d'autres sites comme celui-ci vous donnera également un bon aperçu des capacités de mise en page et de conception.
