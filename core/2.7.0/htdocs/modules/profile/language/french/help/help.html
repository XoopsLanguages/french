DESCRIPTION

Le module Profil permet de gérer les champs de profil utilisateur personnalisés.

INSTALLER/DÉSINSTALLER

Aucune mesure particulière n'est nécessaire, suivez le processus d'installation standard – extrayez le dossier /profile dans le répertoire ../modules. Installez le module via Admin -> Module système -> Modules.

Des instructions détaillées sur l'installation des modules sont disponibles dans le Manuel d'utilisation XOOPS

INSTRUCTIONS D'UTILISATION

Pour configurer ce module, vous devez :

  • Configurez vos préférences pour le module (voir 'Préférences') et éventuellement le bloc Profil si vous comptez l'utiliser (voir 'Blocs').
  • Modifiez les catégories existantes ou ajoutez-en de nouvelles.
  • Modifiez les champs existants ou ajoutez-en de nouveaux. Ici, vous pouvez spécifier quels champs seront visibles dans quelle catégorie et s'ils seront visibles lors de l'enregistrement de l'utilisateur.
  • Définit l'ordre des étapes d'inscription.
  • Et enfin, vous pouvez définir des autorisations pour des champs individuels : lesquels sont modifiables, lesquels peuvent être recherchés.

Mesures anti-spam

Pour minimiser les enregistrements de spam, procédez comme suit :

  • allez dans le module Protector dans Admin, allez dans Préférences, puis en bas, à cette option : "Arrêtez le spam du forum" Vérifie les données POST par rapport aux spammeurs enregistrés sur la base de données www.stopforumspam.com.
    Réglez-le sur "Bannir l'IP (sans limite)"

  • dans /class/captcha/config.php, assurez-vous que le mode est défini sur "text" :

    return $config = tableau(
    'disabled' => false, // Désactiver CAPTCHA
    'mode' => 'text', // mode par défaut, vous pouvez choisir 'text', 'image', 'recaptcha' (nécessite une clé API)
    'nom' => 'xoopscaptcha', // nom du captcha
    'skipmember' => true, // Ignorer la vérification CAPTCHA pour les membres
    'maxattempts' => 10, // Nombre maximum de tentatives pour chaque session
    );

  • Dans le module Profil, allez dans Admin et dans l'étape Basique située à l'adresse :
    /modules/profile/admin/step.php?id=1
    définissez "Enregistrer après l'arrêt" sur "Non"


  • Dans les Préférences de profil, définissez l'option « Utiliser le Captcha après la deuxième étape d'inscription » sur « Oui » (c'est la valeur par défaut)
