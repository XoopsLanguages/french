Aide : Blocs

Descriptif

Les blocs sont des sections discrètes de contenu qui peuvent être créées et configurées dans l'interface d'administration. Des blocs personnalisés peuvent être créés et sont généralement constitués de texte, de graphiques et d'images. Le contenu de ces blocs peut être formaté individuellement ou hériter du formatage du site. Les blocs peuvent également faire partie de la sortie d'affichage d'un module. La page d'administration des blocs est l'endroit où tous les blocs sont configurés et administrés.

Les blocs sont comme la Une d'un journal : ce sont des teasers qui incitent les lecteurs à lire des histoires plus complètes dans les pages intérieures. Les blocs offrent de petits morceaux de contenu dynamique avec des liens vers le contenu réel stocké dans le module.

Une partie des choses qui se produisent sous le capot ou derrière les rideaux lorsqu'un module est installé dans un site XOOPS est que les blocs du module sont enregistrés dans le système, afin qu'ils puissent être utilisés à volonté par le webmaster.

Que peut faire un webmaster avec un blocage ? Eh bien, surtout, décidez où dans le site le bloc sera affiché (l'équivalent de définir une vitrine, qui dans ce cas peut être à l'extérieur, sur la page d'accueil, ou même à l'intérieur : un bloc peut être défini pour être affiché dans d'autres modules), et quand affiché, où dans une page il sera vu.

Chaque module installé dans un site XOOPS enregistre ses blocs dans le système, et le webmaster peut décider où il sera affiché, dans quelle partie de la page il apparaîtra et quel type de pertinence, de poids ou de position aura-t-il. L'administrateur du site peut également modifier le titre du bloc et, s'il est suffisamment compétent, peut même modifier le modèle qui sous-tend la présentation du bloc.

Conseils

Vous pouvez masquer le titre qui s'affichera lorsque le bloc sera affiché en ajoutant "// " (c'est-à-dire slash-slash-space) comme les trois premiers caractères du titre. De cette façon, vous pouvez joindre de manière transparente plusieurs blocs pour créer la vue souhaitée.

Vous pouvez créer vos propres blocs de contenu à l'aide de l'icône "Ajouter un blocbouton ". Vous pouvez créer votre propre contenu en HTML, en texte brut avec les codes XOOPS, ou même en PHP. Dans vos blocs personnalisés, le code "{X_SITEURL}" sera remplacé par l'URL de votre site avec une barre oblique finale.
