Bienvenue dans : Centre d'aide XOOPS

Comment utiliser XOOPS ?

XOOPS est une plateforme d'applications web écrite en PHP pour la base de données MySQL. Son orientation objet en fait un outil idéal pour développer des sites Web communautaires de petite ou grande taille, des portails intra-entreprise et d'entreprise, des blogs et bien plus encore. Afin d'utiliser XOOPS efficacement, vous devez installez des modules qui fournissent les fonctionnalités que vous recherchez. Il existe de nombreux modules différents dans Référentiel de modules, des calendriers, galeries de photos, en passant par les actualités, les tableaux d'affichage, jusqu'à mises à jour météo.

Comment utiliser le centre d'aide ?

Le Centre d'aide a pour but de vous fournir des informations de base relatives aux fonctionnalités individuelles de l'administration. Chaque fois que vous souhaitez en savoir plus sur une page particulière sur laquelle vous vous trouvez, cliquez simplement sur l'icône d'aide dans le coin droit.

Comment puis-je créer du contenu dans XOOPS ?

Vous aurez besoin d'un module pour cela. Il peut s'agir d'un module Actualités ou d'un module Contenu.

Comment puis-je obtenir davantage d'aide ?
