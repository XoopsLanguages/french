Aide : Smileys

Descriptif

Les sourires sont de petits symboles graphiques que les gens peuvent utiliser pour s'exprimer. Ils peuvent être insérés n’importe où dans le texte d’un article, d’un commentaire ou d’une publication, tant du côté utilisateur que administrateur du système. XOOPS est livré avec une collection de 17 smileys intégrés. Certains d'entre eux sont affichés sur le formulaires de soumission dans divers modules (y compris forums, actualités, téléchargements, liens et autres). Cliquer sur un smiley l'insérera dans la publication. Les smileys peuvent également être insérés en tapant leurs « codes » uniques (raccourcis clavier), par exemple en tapant ':' '-' 'D' dans un message insérera ce smiley :

La liste complète des smileys disponibles sur votre système et leurs codes sont accessibles via les smileys, où vous vous trouvez actuellement. Ici, vous pouvez ajouter, modifier et supprimer des smileys, et contrôler ceux qui sont affichés sur les formulaires de soumission (seulement neuf sur 17 sont affichés par défaut)

Si vous ne voulez pas de smileys sur votre système, vous pouvez soit décocher la case « afficher sous formulaire ? (auquel cas ils n’apparaîtront pas sur les formulaires de soumission, mais seront toujours disponibles via leurs codes), ou utilisez le lien de suppression pour les supprimer entièrement.
