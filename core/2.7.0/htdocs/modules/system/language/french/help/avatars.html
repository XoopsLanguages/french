Aide : Avatar

Descriptif

Les avatars sont de petits graphiques ou images qui peuvent être utilisés dans divers paramètres de contenu sur le site. Ils sont souvent utilisés à côté d’un nom d’utilisateur pour ajouter un peu d’« identification visuelle ». Les applications typiques sont le forum.

Le gestionnaire d'avatars permet à l'administrateur du site d'ajouter, de modifier ou de supprimer des avatars système ainsi que des avatars personnalisés.

Avatar du système

Les avatars système sont des images téléchargées par l'administrateur du site dans la section Gestionnaire d'avatars.

Avatar personnalisé

Les avatars personnalisés sont des images directement téléchargées par un utilisateur. Pour qu'un utilisateur puisse télécharger un avatar, l'option correcte doit être configurée dans les paramètres d'informations utilisateur des préférences du site.

Modifier et supprimer des avatars

L'administrateur du site peut modifier le nom et l'ordre d'affichage de tous les avatars système, ainsi que supprimer n'importe lequel d'entre eux. Notez que si l'administrateur du site supprime un avatar qu'un utilisateur utilise, cet utilisateur perdra son avatar.
