Aide : Bannières

Descriptif

Les bannières sont des publicités affichées dans la partie supérieure de la page. Il peut s'agir d'images ou de films flash, par ex. la bannière XOOPS extrêmement tournoyante qui fait partie de l’installation par défaut. XOOPS dispose d'un système intégré de gestion des bannières et de création de comptes pour les clients publicitaires, qui est trouvé dans le module système -> Bannières. Vous pouvez avoir plusieurs bannières sur un site XOOPS – la zone d'affichage tourne tour à tour à travers chacune des bannières actives à chaque fois qu'une nouvelle page est chargée.

Chaque fois qu'une bannière est affichée à un visiteur, cela compte comme une « impression », qui est la monnaie d'échange commune des bannières. Les clients paient généralement pour un certain nombre d'impressions, c'est-à-dire pour que leur publicité soit affichée un certain nombre de fois.

Veuillez noter : si vous vendez des bannières en fonction du nombre d'impressions, vous devez faire une chose importante : allez dans le module système -> Préférences -> Paramètres généraux et remplissez le champ « Votre adresse IP » (si vous en avez une). Cela empêchera vos visites au site d'être inclus dans le nombre d'impressions. Ne pas le faire pourrait être considéré comme quelque peu malhonnête (à noter toutefois que de nombreux administrateurs ne disposent pas d’une adresse IP permanente – par exemple ceux qui utilisent des modems commutés).
