DESCRIPTION

Le module PM est destiné à la messagerie privée entre utilisateurs

INSTALLER/DÉSINSTALLER

Aucune mesure particulière n'est nécessaire, suivez le processus d'installation standard – extrayez le dossier /pm dans le répertoire ../modules. Installez le module via Admin -> Module système -> Modules.

Des instructions détaillées sur l'installation des modules sont disponibles dans le Opérations XOOPS Manuel

INSTRUCTIONS D'UTILISATION

Pour configurer ce module, vous devez :

  • Vous entrez dans votre boîte de réception directement depuis la page d'accueil ou en cliquant sur le lien supérieur « Aller au module » dans la zone d'administration du PM.
  • Configurez vos préférences pour le module (voir « Préférences ») et éventuellement le bloc PM si vous comptez l'utiliser (voir « Blocs »).
  • Vous pouvez effectuer une suppression massive de vos messages en utilisant l'onglet "Élaguer" les messages.
