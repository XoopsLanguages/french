Aide : Envoyer un courrier électronique aux utilisateurs

Descriptif

XOOPS dispose d'un système de messagerie intégré qui vous permet d'envoyer un message à l'ensemble de votre base d'utilisateurs enregistrés ou à des sous-groupes de celle-ci, ou à l'aide de filtres de date. Cela peut prendre la forme d'un message privé (c'est-à-dire via le système de messagerie intégré XOOPS) ou via un e-mail. Une gamme d'options est disponible pour filtrer les sous-groupes d’utilisateurs de votre adhésion.

Vous pouvez également utiliser des balises prédéfinies qui vous permettront de personnaliser votre message.
